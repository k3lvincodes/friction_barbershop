# Friction Barbershop — Warri, Nigeria

Premium grooming experience in the heart of Warri. Built with React + TypeScript + Vite.

## Tech Stack

- **React 19** — functional components + hooks
- **TypeScript**
- **Vite** — build tool
- **Framer Motion** — animations
- **Google Fonts** — Playfair Display, Cormorant Garamond, DM Sans, Bebas Neue, Bodoni Moda

## Sections

1. **Navbar** — sticky with blur backdrop, mobile hamburger drawer
2. **Hero** — full-viewport with background image, animated headline, CTA buttons, ticker tape
3. **About** — brand story with quote, stat cards (ratings, hours)
4. **Services** — 6 service cards with image backgrounds and hover effects
5. **Bar & Snooker** — "The Spot" gallery with auto-rotating images
6. **Experience** — diagonal clip-path break section
7. **Hours & Location** — hours table + Google Maps embed + Get Directions
8. **Reviews** — horizontal scrollable review cards
9. **Footer** — CTA banner, nav links, Instagram/WhatsApp social icons

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
